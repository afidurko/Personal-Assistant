# Aaron Brain — Cam Starter Vault

This Obsidian vault is Cam’s recommended second brain for Aaron.

## Open it

1. Install [Obsidian](https://obsidian.md)
2. **Open folder as vault** → select this `vault/` directory (inside Personal-Assistant)
3. Settings → Community plugins → browse **Smart Second Brain** → Install → Enable
4. Tell Cam if you move the vault; path is tracked in `../config/persona/vault.json`

## Map

| Folder | Purpose |

## Rules

- Aaron is the only task-giver
- Cam may write here when working your tasks (standing autonomy)
- Prefer linking notes (`[[Note]]`) over duplicating
- Consequential decisions get a short “Decision” section + date
