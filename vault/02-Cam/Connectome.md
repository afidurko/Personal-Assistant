# Cam Connectome

Cam’s system architecture mirrors neuron/brain mapping (Berg et al., Cell 2026):

- Shared sensory periphery (now includes arXiv/AGI feeds + daily clock + sLM/DL feedback)
- Specialized higher centers + hotspots (**agi_scan**, **enhance**, **capability**, **info**, **slm**, **dl**)
- Circuit switches for antagonistic outcomes (`research_scan` vs pause; `cam_enhance` propose vs apply)
- Motor effectors that only fire on mapped **act** pathways (`web_fetch`, `enhance`, `slm`, `dl`, …)
