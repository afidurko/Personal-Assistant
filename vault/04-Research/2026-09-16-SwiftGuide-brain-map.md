# SwiftGuide → Cam brain map

Source submodule: `integrations/swiftguide`  
Integration: `config/integrations/swiftguide.md`  
Mind-map config: `config/connectome/mindmap.json`

## Why it belongs on the connectome

SwiftGuide shows how **long-lived Markdown** can stay useful when treated as a
**mind-map knowledge asset** (Classification map + Application-architecture map +
2026 ecosystem report). Cam’s vault and connectome already think in pathways;
SwiftGuide adds a second lens: **browseable trees**, not only RAG hits.

| Lens | Question it answers |
|---|---|
| Nervous system (CNS) | How does a spike become motor action? |
| Mind map (SwiftGuide pattern) | How is knowledge / stack taxonomy organized? |

## What Cam should pull from it

1. **Cartography center** (`center.cartography`) — hierarchical map queries via `sense.swiftguide.map`
2. **iOS companion stack picks** — local-first, SwiftUI, TCA, Markdown assets (see mindmap.json)
3. **Vault maintenance pattern** — keep project maps as trees that age well (DeMinds / SwiftGuide ethos)

## Not a second brain

smart-second-brain still owns vault search/graph. SwiftGuide is a **curated map corpus**
Cam consults for Swift/iOS cartography and for structuring knowledge assets.
