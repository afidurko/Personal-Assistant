# How to open this vault

1. Install Obsidian from https://obsidian.md
2. Open Obsidian → **Open folder as vault**
3. Choose the `vault` folder inside this Personal-Assistant repo
4. Enable Community plugins → install **Smart Second Brain**
5. Keep working here; Cam is pointed at this vault via `config/persona/vault.json`

If you clone the repo elsewhere, update `vault_path` to the absolute path on that machine.
