# MindAR image targets

Compile the printable card faces in `../assets/` with the MindAR image target
compiler and place the resulting `targets.mind` file here:

https://hiukim.github.io/mind-ar-js-doc/tools/compile

Suggested order (matches `mindar.html` targetIndex map):

0. `card-volt-wisp.svg`
1. `card-ember-drake.svg`
2. `card-tide-finch.svg`

Until this file exists, use `../index.html` lab mode.
